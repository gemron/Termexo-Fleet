# 开源了一个本地多机 AI 编程 Agent 调度台：Termexo Fleet（支持 L1-L4 难度路由、异构审与实时 PTY 接管）

节点建议：`分享创造`（`https://www.v2ex.com/go/create`）

---

最近自己同时在 Windows 主力机和局域网 Mac 上跑 Claude Code、Codex CLI 和 OpenCode，遇到几个挺实际的问题：

1. 改几行文档和注释也一直烧最贵模型的配额，有点浪费；
2. 遇到 429 限流或登录过期，任务就卡死在那里等人工切号；
3. 同一个模型写完并发/安全逻辑又自己做 Review，还是容易漏掉边界问题；
4. 很多黑盒多 Agent 脚本看不到实时终端，卡在交互确认的时候很难接管。

于是用 Rust + Tauri 2 + Angular 22 做了个本地优先的开源桌面调度控制面 **Termexo Fleet**（MIT 协议，刚发 `v0.1.1`），直接编排本机或局域网里的 Termexo 实例：

- **零黑盒执行**：所有任务和子 Agent 都跑在真实的 Termexo PTY 终端里，点开滑出式终端抽屉随时能看日志，也能直接点 `同意 (y)` 或输入指令接管；
- **L1–L4 难度天梯**：按复杂度把轻量改动分给低成本快模型（L1），架构重构分给顶级推理模型（L3），L4 审查会自动排除上游作者的模型家族（比如 Claude 写完强制让 Codex 复核）；
- **反向 MCP 自主蜂群**：内置 `127.0.0.1:7425/mcp`，父 Agent 可以提交多阶段 DAG 或派生子 Agent，自动隔离 Git Worktree，并带递归深度、并发和总预算护栏；
- **本地 SQLite 账本 & 多通道告警**：记录真实耗时、容灾切号次数和相对全量 L3 的估算省费比例，支持飞书 / 企微 / Slack / 微信提醒。

支持 Windows x64、macOS（Apple Silicon & Intel）和 Linux x64，有 Node.js 18.18+ 的话可以直接一行拉起：

```bash
npx termexo-fleet@latest
```

说明两点前提：需要搭配运行中的 Termexo 与你自己的 Agent CLI/账号使用；目前 Windows 包未做商业签名，macOS 为临时签名（首次打开需在隐私与安全性里允许）。
